# Подписи выбранных оператором полей

Задача `localize-operator-field-labels-v1`, worker `operator-label-engineer`, fence 1. Изменено только представление имён полей в типизированном блоке таблицы `packages/extractor/operator.ts`. Это небольшая правка подписей, не законченный дизайн и не результат designer skill.

| Исходное имя          | Подпись в таблице                  |
| --------------------- | ---------------------------------- |
| `title`               | Название                           |
| `availability`        | Наличие на странице источника      |
| `displayed_price_N`   | Цена на странице источника (N + 1) |
| `promotion`           | Акция на странице источника        |
| `description_excerpt` | Фрагмент описания                  |

Для цены принимается канонический десятичный индекс от 0 до 4999 без знака и ведущих нулей (кроме самого `0`), в пределах контракта 5000 выбранных полей. Иные индексы, регистр и неизвестные имена сохраняются дословно. Нумерация отражает только исходный индекс поля; она не назначает ценам смысл «старая», «новая», «действующая», «со скидкой» или валюту.

Значения, пробелы и переносы строк сохраняются. `raw_selected_fields.name`, locator, evidence и `operator_field:*` facts по-прежнему содержат исходные данные. Таблица хранит текстовые строки, а существующий собственный PHP-форматтер экранирует подписи и значения. Unknown labels не исполняются, в том числе имена `__proto__`, `constructor` и текст HTML. Нормализованные `prices`/`offers` не добавляются; price/availability остаются UNKNOWN. Source inventory, access block, PARTIAL и неизвестная полная величина сайта не меняются. Старые принятые capture/model артефакты не перезаписываются: обновлённая модель будет создана root обычным исполнителем с новым fingerprint.

Проверено локально:

```powershell
npm run check
$env:UPGRADE_PHP_BIN = (Resolve-Path 'var/tools/php-8.3.35/php.exe').Path
node --disable-warning=ExperimentalWarning --test tests/integration/operator-extraction.test.ts
```

TypeScript — PASS; **19/19 tests PASS, 0 SKIP** с PHP 8.3.35. Новые проверки отделяют presentation от raw/provenance, проверяют границы индекса и сохранение двух неоднозначных цен. Тест экранирования вызывает существующий чистый метод `Gateway::fields` через PHP Reflection без конструктора, bootstrap CMS, Store, подключения или записи в БД; неизвестная HTML-подпись и значение остаются текстом в итоговых ячейках. Без `UPGRADE_PHP_BIN` именно PHP-проверка явно SKIP, а не PASS.

Сервер, пилотные артефакты и БД этим исполнителем не изменялись. Новая сборка, повторный импорт и визуальная HTTP/браузерная приёмка обновлённых подписей выполняются root отдельно; в этой задаче они **NOT_RUN**.
