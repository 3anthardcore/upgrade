# r17 — accepted QA and operational tools

This application release adds the reviewed native QA receipt importer/reporter, bounded native browser verifier, GET-only privacy/performance measurement and current-runtime backup runner. It does not change the installed CMS package or publish DEMO_READY.

The release is assembled from an isolated source snapshot. Ongoing `current-state-recovery-20260930` implementation files and the still-open performance diagnosis report are explicitly excluded: `scripts/recovery-current-runtime.py`, `tests/unit/current-runtime-recovery.test.ts`, `docs/reviews/current-runtime-recovery-20260930.md`, `docs/reviews/native-performance-diagnosis-20260930.md`. Their absence means they are not released or accepted. Independent work may continue in the main workspace while checks run against this immutable candidate snapshot.

Accepted scopes and prior failures are recorded in the root/independent review reports. Native QA imports operator-copied evidence, validates consistency and preserves source denominator/NOT_RUN gates. Its recorded evidence is not a new inspection of the remote deployment. Current runtime backup is distinct from the existing historical SQL/CMS restore; current private-session restoration needs the separate unreleased recovery implementation.

Full candidate checks and archive/deployment hashes are recorded after actual execution in the pilot progress report.
