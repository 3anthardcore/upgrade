# Расширение диска предоставленного сервера

Проверка и расширение 29 сентября 2026: хост `148.135.208.53` (`nl-vmnano`), Ubuntu 22.04.5. После подтверждения пользователя «Продолжай» дополнительное пространство включено в раздел/LVM/ext4. Следующая таблица сохраняет исходную диагностику.

| Уровень | Наблюдаемый размер |
|---|---:|
| `/dev/sda` | 171798691840 bytes, 160 GiB |
| `/dev/sda3` | 63348653568 bytes, около 59 GiB |
| LVM `hk/root` | 63346573312 bytes, около 59 GiB |
| ext4 `/` | `df -h`: 58G, свободно около 502M |
| Свободное место в VG `hk` | 0 |

Тарифный диск уже увеличен. Дополнительное пространство осталось вне раздела, поэтому `df` ещё показывает старую ёмкость. Перезагрузка и переустановка не являются необходимым первым шагом.

Сохранены `/root/upgrade-preflight/sda-before-20260929.sfdisk` и `/root/upgrade-preflight/hk-before-20260929.vgcfg`. Это копии метаданных разделов и LVM, не резервные копии данных сайтов.

Выполнен `growpart -N /dev/sda 3`: начало раздела остаётся 2101248 sectors; длина меняется с 123727839 на 333443039 sectors. `-N` означает dry-run, запись не выполнялась.

Выполнено после повторной проверки устройств и создания свежих копий `sda-before-apply-20260929T0123.sfdisk` и `hk-before-apply-20260929T0123.vgcfg`. Команды выполнялись по одной с проверкой результата; повторять расширение не требуется:

```sh
lsblk -b -o NAME,SIZE,TYPE,FSTYPE,MOUNTPOINTS
findmnt /
pvs
vgs
lvs
growpart /dev/sda 3
lsblk -b /dev/sda
pvresize /dev/sda3
pvs
vgs
lvextend -l +100%FREE -r /dev/hk/root
df -hT /
lvs
systemctl is-active nginx docker
docker ps --format '{{.Names}} {{.Status}}'
```

При несовпадении устройств/типов или ошибке остановить зависимые шаги. Ничего не удалять для освобождения места, не менять разметку чужих дисков и не пытаться автоматически уменьшать выросшую ext4.

Результат: `/dev/sda3` 170722835968 bytes, `/dev/hk/root` 170720755712 bytes; `df -hT /`: ext4 **157G**, занято **55G**, доступно **95G**, **37%**. Перезагрузка не потребовалась. `nginx -t` PASS, nginx/docker active, прежние 22 контейнера работают. Доказательства на сервере: `/root/upgrade-preflight/disk-after-20260929.json`, `df-after-20260929.txt`; локально `var/evidence/server-capacity-result.json`.

Продолжена [изолированная установка приложения](app-deploy.md). Системный Node и конфигурации существующих сайтов сохраняются. Секреты SSH в проекте не хранятся. Расширение диска не подтверждает восстановление данных сайтов.
