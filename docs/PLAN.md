# План реализации

Состояние стадий и фактические проверки: [PROGRESS.md](PROGRESS.md). Требования исходного ТЗ не являются подтверждением реализации.

| Этап | Результат | Критерий завершения |
|---|---|---|
| 0 | Инструкции, схемы, профили, doctor | Проверяемые версии и явные блокеры |
| 1 | SQLite, CLI, leases, budget, immutable artifacts | Тесты восстановления, stale results, независимой приёмки |
| 2–3 | HTTP/browser crawl, извлечение, URL, scope | Эталонный источник, вредоносные данные и сложные URL проверены |
| 4 | Собственный модуль, шаблон, импортёр Битрикс | Настоящий импорт и редактирование в лицензированном окружении |
| 5 | Codex CLI adapter, dispatcher, роли | Два реальных параллельных исполнителя; результаты приняты отдельно |
| 6–7 | Сборка, QA, отчёт | Проверки всего scope и сценариев, без ложного DEMO_READY |
| 8 | Release, backup/restore | Восстановление отдельной копии и smoke test |
| 9 | Три пилота | Реальные демо услуг, каталога и магазина с замерами |

Сначала исполняемый вертикальный срез с синтетическим источником. Отсутствующие сервер, лицензия и пилотные адреса блокируют только соответствующие интеграционные испытания. Реализация продолжает независимые стадии.
