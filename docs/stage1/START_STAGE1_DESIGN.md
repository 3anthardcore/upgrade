# Задание Codex на первый этап Upgrade

Реализуй веб-сервис по [UPGRADE_STAGE1_DESIGN_SPEC.md](UPGRADE_STAGE1_DESIGN_SPEC.md).

Пользователь вставляет ссылку на сайт, ИИ изучает реальные страницы и скриншоты, затем сервис выдаёт новый индивидуальный дизайн главной страницы в виде картинки. По умолчанию результат — целая главная для компьютера, одним вертикальным PNG. Нужны просмотр, скачивание и правка по текстовому пожеланию.

Используй только новое ТЗ этого этапа. Старые задания про перенос всех страниц, Битрикс, CLI-платформу и сложную команду агентов сейчас не реализуй.

Начни с маленького реального сквозного примера: сайт → исходный снимок и факты → дизайн-бриф → вызов модели генерации → проверенный PNG. Выясни, как обеспечить читаемый русский текст, точный логотип и целую композицию. Только после получения такого результата доводи веб-интерфейс и остальные функции.

Далее соедини процесс с формой ссылки и серверной обработкой. Пользователь должен получать картинку без ручной работы разработчика между этапами. Модель генерации вызывается сервером через доступный API; ключи остаются на сервере. Если ключ или доступ к API отсутствует, укажи конкретный блокер и не подменяй генерацию заглушкой.

Не своди результат к одному фиксированному шаблону, случайному лендингу, текстовому аудиту или перекрашенному скриншоту исходника. Факты о бизнесе бери из источника, не выдумывай цены и отзывы. Для точного текста и логотипа допускается простой слой композиции с экспортом в PNG.

Держи реализацию простой: одно веб-приложение, фоновые задания, хранилище результатов, браузерное исследование и этапы анализа, генерации и проверки. Отдельная распределённая платформа не нужна.

Проверь результат на трёх разных сайтах. Покажи фактические исходные скриншоты и итоговые картинки. Не объявляй сервис готовым, пока новый URL не проходит весь путь через интерфейс с настоящей генерацией.

В итоговом отчёте укажи, что реализовано, как открыть сервис, какие проверки выполнены, где лежат примеры и какие ограничения остались. Выполняй работу поэтапно и сохраняй полезный существующий код; не удаляй прежний проект без отдельного задания.
